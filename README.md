# HerbalPlantsLeafPy

Flask web application for herbal plant leaf prediction and chatbot responses.

## 1) Scanned files

Dependencies were generated by scanning only these Python files:

- `App.py`
- `chatbot.py`
- `train.py`
- `LeafModel.py`

The `venv/` directory was excluded intentionally.

## 2) Install dependencies

Run from the project root:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## 3) NLTK data setup (required for sentiment)

`chatbot.py` uses VADER sentiment (`SentimentIntensityAnalyzer`), which requires the VADER lexicon:

```bash
python -c "import nltk; nltk.download('vader_lexicon')"
```

## 4) Database setup

This project now uses MongoDB.

Set environment variables before starting the app.

PowerShell:

```powershell
$env:MONGO_URI="mongodb://localhost:27017"
$env:MONGO_DB_NAME="3herbalchatmondb"
```

CMD:

```cmd
set MONGO_URI=mongodb://localhost:27017
set MONGO_DB_NAME=3herbalchatmondb
```

Collections used by the app:

- `regtb`
- `reporttb`

## 5) Run the project

### Train chatbot data

```bash
python train.py
```

### Run the main Flask app

```bash
python App.py
```

Open:

- `http://127.0.0.1:5000/`

### Optional: chatbot-only page

```bash
python chatbot.py
```

Open:

- `http://127.0.0.1:5000/`

## 6) Prediction prerequisites

- `model.h5` must exist in the project root (already present).
- `Data/` must contain class subfolders and training images (already present).
- Image upload flow writes the test image to `static/Out/Test.jpg`.

If `static/Out` does not exist, create it:

```bash
mkdir static/Out
```

## 7) Quick end-to-end verification

1. `python train.py` completes without import errors.
2. `python App.py` starts the Flask server.
3. Registration/login pages load.
4. Chat endpoint returns a response.
5. Predict page accepts an image and returns a result.
